## Preprocessed data files

- `c_counts_psy_2001_2023.RDS` contains citation statistics for the field of psychology in the years 2001 - 2023. It is used to compute the field- and age-normalized citation counts (FNCS).
- `h_index_comparison.csv` has the raw data for the comparison of automatically retrieved h-indexes (from OpenAlex, computed by the OAmetrics R package) and manually retrieved h-indexes from Scopus.
- `S2_data.Rdata` and `S2.csv` contain the raw data for the S2 indicators.
- `S2_indicator_correlations.csv` contains the correlation matrix of the S2 indicators. The diagonal has Krippendorff’s alpha.
